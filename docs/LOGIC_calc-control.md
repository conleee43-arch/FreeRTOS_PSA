# LOGIC_calc-control — 内阻九段测量计算状态机设计说明书

---

## 1. 核心设计目的

为高精度求出动力供电母线的内部直流等效电阻（DCR）以评估电池老化或供电设备内阻特征，系统规划在 `calc_control.c` 中实现一套高精密、单次触发的九段式内阻计算状态机。

本说明书作为内阻计算状态机控制流程和数学解算公式的唯一真理源，用于指导后续 `calc_control.c` 与对应的 `Calc_Control_Task` 的业务代码实现与单元测试。

---

## 2. 内阻计算状态机九段式转换定义 (FSM States)

后续实现的内阻计算状态机规划设计有以下九个独立的状态转移，以实现受控的电流负荷阶跃及精准的同步采样：

| 状态枚举值 | 状态名称 | 核心行为与转移判定条件规划 |
|---|---|---|
| **STATE_WAIT_SAFE** | 安全等待 | 起始状态。等待系统判定为正常安全（来自保护任务的通知），且在触发计算前保持此状态。 |
| **STATE_SET_3A** | 设定 3A 阶跃电流 | 状态机在此状态将控制 DAC 目标物理量阶跃式更改为 $3.0\text{A}$，随后立即跳转至下一状态。 |
| **STATE_WAIT_3A_STABLE** | 等待 3A 电流稳定 | 进行时间窗口倒计时。规划在此状态中等待 $100\text{ms}$，以允许外设物理电感及电容充放电响应完成，硬件达到稳态。 |
| **STATE_LATCH_3A** | 锁存 3A 采样指标 | 倒计时结束后，在极短时间片内执行遥测电压与电流的高精度采样锁存，记录为 $U_1$ 和 $I_1$，随后跳转。 |
| **STATE_SET_2A** | 设定 2A 阶跃电流 | 状态机在此状态将控制 DAC 目标物理量阶跃降落至 $2.0\text{A}$，随后立即跳转。 |
| **STATE_WAIT_2A_STABLE** | 等待 2A 电流稳定 | 进行消抖窗口倒计时。由于是向下阶跃，电平释放较快，规划在此状态中等待较短的时间，完成稳态消抖判定。 |
| **STATE_LATCH_2A** | 锁存 2A 采样指标 | 倒计时结束后，执行第二组高精度遥测电压与电流锁存，记录为 $U_2$ 和 $I_2$，随后跳转。 |
| **STATE_CALC_RESISTANCE** | 执行内阻代数计算 | 运行核心内阻代数求解数学公式，将计算出的阻值入库，并设定限流物理量，随后跳转。 |
| **STATE_MONITOR** | 计算完成与静态监控 | 状态机的终点。在此状态下，内阻计算结束，不再主动更改 DAC 的输出目标，直到接收到重置命令。 |

---

## 3. 内阻核心计算公式与物理量映射

在 `STATE_CALC_RESISTANCE` 状态中，内阻求解规划采用如下的直流等效电阻（DCR）解算公式：

$$R_{int} = \frac{U_1 - U_2}{I_1 - I_2}$$

### 3.1 物理测量通道绑定约束
公式中的参数被强制约束绑定为以下物理测量通道的锁存值，后续实现时严禁从非标准通道提取数据：
- **第一组电压锁存值 ($U_1$)**：在 3A 阶跃稳态时，锁存的直流母线输出电压。数值提取源规划为：`Measure_GetVoOut()`。
- **第一组电流锁存值 ($I_1$)**：在 3A 阶跃稳态时，锁存的直流母线输出电流。数值提取源规划为：`Measure_GetCoOut()`。
- **第二组电压锁存值 ($U_2$)**：在 2A 阶跃稳态时，锁存的直流母线输出电压。数值提取源规划为：`Measure_GetVoOut()`。
- **第二组电流锁存值 ($I_2$)**：在 2A 阶跃稳态时，锁存的直流母线输出电流。数值提取源规划为：`Measure_GetCoOut()`。

## 4. 阶跃稳定窗口与判定机制

为保证计算出的内阻不受瞬态尖峰或阶跃爬坡波形影响，后续状态机实现中判定“稳态”需遵循如下控制策略：

- **3A 大跨度阶跃稳定窗**：规划为 $100\text{ms}$ 倒计时。当状态机切换至 `STATE_WAIT_3A_STABLE` 后，只有当系统 Tick 计数器自该状态开启流逝满 $100\text{ms}$ 时，才认为外围阻抗已达到动态平衡，允许转移至 `STATE_LATCH_3A`。
- **2A 小跨度消抖判定窗**：由于阻抗自感引起的电压回落过程具有指数衰减特征，消抖判定窗时间可适当缩短。只有当时间计数满此消抖窗时，才被允许转移至 `STATE_LATCH_2A`。
- **判定差值约束**：在锁存前，可辅助校验电压物理波动率。若电压变化率超过安全限值，状态机规划标记错误并回退。

---

## 5. 安全动作联动与被重置后的行为控制

内阻计算任务绝不是完全独立的，后续业务代码中必须支持并强制约束以下安全联动行为：

### 5.1 限制最大控制电流策略
- 在内阻核心计算完成瞬间（在 `STATE_CALC_RESISTANCE` 执行完公式），系统规划根据算出的内阻 $R_{int}$ 物理特征，自动计算并更新系统最大的安全控制限制电流，重新设定下发给 DAC 的限制电流物理量 IOC。
- 随后，状态机转移至 `STATE_MONITOR`，完全释放控制权，保证后续业务绝不再次主动改变 DAC 的硬件输出。

### 5.2 状态机紧急退回语义
- 在内阻状态机运转的任何阶段（无论是处于 3A 阶跃还是锁存阶段），如果高优先级的保护任务（`Emergency_Task`）因发现物理量越限而调用重置接口 `Calc_Control_Reset()`：
  - 内阻状态机必须以**原子级操作**立刻终止当前的所有计时、采样和 DAC 控制行为。
  - 状态机状态必须**强行退回到起点状态 `STATE_WAIT_SAFE`**。
  - 只有在保护任务通知安全警告解除且系统重新进入正常状态后，才允许开启下一次单次触发测量。
