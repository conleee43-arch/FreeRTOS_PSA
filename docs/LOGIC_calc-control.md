# LOGIC_calc-control — 内阻九段测量计算状态机设计说明书

---

## 1. 核心设计目的

为高精度求出动力供电母线的内部直流等效电阻（DCR）以评估电池老化或供电设备内阻特征，系统在 `calc_control.c` 中实现了一套高精密、单次触发的九段式内阻计算状态机。

本说明书作为内阻计算状态机控制流程和数学解算公式的唯一真理源，用于约束 `calc_control.c` 与对应 `Calc_Control_Task` 的业务代码实现与单元测试。

---

## 2. 内阻计算状态机九段式转换定义 (FSM States)

当前内阻计算状态机包含以下九个独立的状态转移，以实现受控的电流负荷阶跃及精准的同步采样：

| 状态枚举值 | 状态名称 | 核心行为与转移判定条件 |
|---|---|---|
| **STATE_WAIT_SAFE** | 安全等待 | 起始状态。等待系统判定为正常安全（来自保护任务的通知），且在触发计算前保持此状态。 |
| **STATE_SET_3A** | 设定 3A 阶跃电流 | 状态机在此状态将控制 DAC 目标物理量阶跃式更改为 $3.0\text{A}$，随后立即跳转至下一状态。 |
| **STATE_WAIT_3A_STABLE** | 等待 3A 电流稳定 | **核心自循环状态**。每 10ms 唤醒一次，内部 100ms 分频采样电流并与上次采样值作差值判定。若连续 5 次差值均 ≤ 500mA 则判定稳定，否则原地自循环并释放 CPU。可能的等待时间为 1 秒至无限长。 |
| **STATE_LATCH_3A** | 锁存 3A 采样指标 | 倒计时结束后，在极短时间片内执行遥测电压与电流的高精度采样锁存，记录为 $U_1$ 和 $I_1$，随后跳转。 |
| **STATE_SET_2A** | 设定 2A 阶跃电流 | 状态机在此状态将控制 DAC 目标物理量阶跃降落至动态值 $I_1 - 1.0\text{A}$（限制在 $[0.1\text{A}, 10.0\text{A}]$ 区间内），随后立即跳转。 |
| **STATE_WAIT_2A_STABLE** | 等待 2A 电流稳定 | 进行消抖窗口倒计时。当前实现等待 10s（由 `STEP_2A_STABLE_MS = 10000U` 定义），以完成 2A 阶跃后的稳态观察；该窗口支持调试命令挂起/恢复。 |
| **STATE_LATCH_2A** | 锁存 2A 采样指标 | 倒计时结束后，执行第二组高精度遥测电压与电流锁存，记录为 $U_2$ 和 $I_2$，随后跳转。 |
| **STATE_CALC_RESISTANCE** | 执行内阻代数计算 | 运行核心内阻代数求解数学公式，将计算出的阻值入库，并发布包含 IOC 观测值的计算报告，随后跳转。 |
| **STATE_MONITOR** | 计算完成与静态监控 | 状态机的终点。在此状态下，内阻计算结束，不再主动更改 DAC 的输出目标，直到接收到重置命令。 |

## 3. 内阻核心计算公式与物理量映射

在 `STATE_CALC_RESISTANCE` 状态中，内阻求解采用如下的直流等效电阻（DCR）解算公式：

$$R_{int} = \frac{U_1 - U_2}{I_1 - I_2}$$

### 3.1 物理测量通道绑定约束
公式中的参数被强制约束绑定为以下物理测量通道的锁存值，严禁从非标准通道提取数据：
- **第一组电压锁存值 ($U_1$)**：在 3A 阶跃稳态时，锁存的直流母线输出电压。数值提取源为：`Measure_GetVoOut()`。
- **第一组电流锁存值 ($I_1$)**：在 3A 阶跃稳态时，锁存的直流母线输出电流。数值提取源为：`Measure_GetCoOut()`。
- **第二组电压锁存值 ($U_2$)**：在 2A 阶跃稳态时，锁存的直流母线输出电压。数值提取源为：`Measure_GetVoOut()`。
- **第二组电流锁存值 ($I_2$)**：在 2A 阶跃稳态时，锁存的直流母线输出电流。数值提取源为：`Measure_GetCoOut()`。

### 3.2 分母差值信噪比保护
为防范环境噪声引起分母极小波动放大计算误差，引入了差值门槛保护策略。只有当实际采样的电流跌落差值 $\Delta I = I_1 - I_2 \ge 0.2\text{A}$ 时才执行除法解算，否则判定测量无效并强行将阻值置为 $0.000\Omega$。

## 4. 阶跃稳定窗口与判定机制

为保证计算出的内阻不受瞬态尖峰或阶跃爬坡波形影响，状态机判定“稳态”需遵循如下控制策略：

### 4.1 3A 大跨度阶跃稳定窗（旧版定时等待）

> ⚠️ **已废弃**：旧版设计采用固定 100ms 倒计时判定稳定，已改为动态电流差值判定机制。

### 4.2 3A 阶跃稳定动态判定机制

**核心自循环设计**：进入 `STATE_WAIT_3A_STABLE` 后，状态机以 10ms 为基础唤醒周期，在内部通过时间分频实现 100ms 电流采样比对。

**判定流程**：

1. **首次进入**：初始化上次电流采样值为当前电流，连续稳定计数器清零
2. **分频采样**：每 100ms 读取一次当前电流 $I_{current}$，与上次采样值 $I_{prev}$ 作差值：
   - 差值计算：$\Delta I = |I_{current} - I_{prev}|$
3. **跳转条件**：
   - **未稳定**：若 $\Delta I > \text{CURRENT\_DELTA\_THRESHOLD\_MA}$（默认 500mA），重置连续稳定计数，状态机原地自循环，退出本次轮询释放 CPU
   - **真正稳定**：若连续 $N$ 次（默认 $N=5$）差值均极小，则进入**开路检测**阶段

**宏定义约束**：
| 宏名称 | 默认值 | 单位 | 说明 |
|---|---|---|---|
| `STEP_3A_POLL_INTERVAL_MS` | 10 | ms | 状态机轮询周期 |
| `STEP_3A_SAMPLE_INTERVAL_MS` | 100 | ms | 电流采样间隔 |
| `CURRENT_DELTA_THRESHOLD_MA` | 500 | mA | 电流差值判定阈值 |
| `STABLE_CONSECUTIVE_COUNT` | 5 | 次 | 连续稳定判定次数 |
| `CURRENT_MIN_THRESHOLD_MA` | 1000 | mA | 开路检测最小电流阈值 |
| `MIN_DI_THRESHOLD` | 0.2 | A | DCR 计算所用的最小电流跌落差值 |
| `MIN_STEP_2A_LIMIT` | 0.1 | A | 第二阶段动态电流阶跃下限 |
| `MAX_STEP_2A_LIMIT` | 10.0 | A | 第二阶段动态电流阶跃上限 |

**稳定判定公式**：
$$\text{Stable} \iff \forall k \in [1, N]: |I_k - I_{k-1}| \leq \text{CURRENT\_DELTA\_THRESHOLD\_MA}$$

**关键特性**：
- **无限期待机**：可能等待 1 秒也可能等待 1 小时，只要电流未稳定就不跳转
- **非阻塞**：每次判定后立即释放 CPU，不占用任务时间片
- **差值单位**：毫安（mA），便于与传感器分辨率对齐

### 4.4 开路检测机制 (Open Circuit Detection)

**问题背景**：当负载外部开路或接近开路时，电流变化几乎为零，使用动态差值判定可能导致误锁存接近 0 的电流值，从而导致内阻计算结果无效。

**检测逻辑**：

当连续稳定判定通过后（连续 $N$ 次差值均 < 500mA），进入开路检测阶段：

1. **检查电流幅值**：读取当前稳定后的电流值 $I_{stable}$
2. **判定条件**：
   - 若 $I_{stable} < \text{CURRENT\_MIN\_THRESHOLD\_MA}$（默认 1000mA），判定为**开路或负载异常**
   - 若 $I_{stable} \geq \text{CURRENT\_MIN\_THRESHOLD\_MA}$，判定为正常负载，状态机继续转移至 `STATE_LATCH_3A`

**开路异常处理**：

当检测到开路时：
- 设置输出标志 `open_circuit_error = 1`
- 锁存开路抑制标志并退回至 `STATE_WAIT_SAFE`，禁止在安全状态维持不变时自动重启 3A 探测
- 保持原设定 DAC 控制量不变，不强制归零，以防扫频或循环探测产生控制电压脉冲抖动
- 调用方可通过 `open_circuit_error` 标志获取错误状态并执行相应处理（如告警、显式复位、等待安全状态重新切换后再触发等）
- **开路状态自动恢复**：在 `STATE_WAIT_SAFE` 安全等待状态下，如果系统监测到物理电流 `co_out_a` 恢复到 $\ge 1.0\text{A}$，则会自动清除开路锁存标志（即 `s_open_circuit_latched = 0`），允许状态机在 `safe_allowed == true` 时自动重新进入 `STATE_SET_3A`。


**判定逻辑图示**：
```
STATE_WAIT_3A_STABLE
        │
        ▼
   [连续5次稳定判定通过]
        │
        ▼
  [当前电流 < 1000mA ?]
        │
   Yes ─┴─ No
    │        │
    ▼        ▼
开路异常   正常锁存
reset      → LATCH_3A
```

**为什么需要开路检测**：
- 开路时电流极小（如 1-2mA），首次采样时 `prev_sample = 0`，导致首次差值就很小
- 若不检测，状态机会快速锁存接近 0 的电流值
- 后续内阻计算时 $\Delta I = I_1 - I_2 \approx 0$，导致内阻计算失败（di < 0.01f 条件触发）
- 通过幅值检测可提前发现开路，避免误测量

### 4.3 2A 小跨度稳态观察窗

由于阻抗自感引起的电压回落过程具有指数衰减特征，当前状态设计等待时间为 10s。只有当时间计数满 `STEP_2A_STABLE_MS = 10000U` 时，才被允许转移至 `STATE_LATCH_2A`。

该 10s 窗口是当前协议视图 `WAIT_2A_STABLE_10S` 的来源；调试挂起期间不推进该等待窗口，恢复后从挂起点继续计算剩余等待时间。

### 4.5 2A 等待挂起/恢复语义

为支持调试场景中的人工观察与节拍冻结，`STATE_WAIT_2A_STABLE` 额外支持“挂起/恢复”控制，但该能力不引入新的 C 状态枚举。

**核心约束**：

- **挂起前提**：只有当前主状态确实位于 `STATE_WAIT_2A_STABLE` 时，才允许进入挂起。
- **挂起语义**：挂起后保持主状态不变，仅设置内部暂停标志并记录挂起时刻。
- **计时冻结**：挂起期间，2A 稳定等待计时器停止推进，不允许因系统 Tick 继续流逝而误进入 `STATE_LATCH_2A`。
- **恢复语义**：恢复时将挂起持续时间追加到该状态的起始时间戳上，使剩余等待时间从挂起点继续计算，而不是从零重新开始。
- **状态视图分离**：核心状态机内部仍保持 `STATE_WAIT_2A_STABLE`；若外部交互需要展示“已挂起”，应通过接口层定义虚拟状态视图，而不是膨胀状态机枚举。

该机制的设计目的是冻结时间推进，而不是改变 2A 等待状态本身的业务含义。

### 4.6 2A 动态设定值与安全限幅防卫

为防范测量电流 $I_1$ 在临界状态或故障状态下的数值异常，在状态机设定第二阶段目标电流时进行算法层的上下限钳位防卫：
- **下限钳位防卫**：计算得到的目标值不得低于 `0.1A`。若 $I_1 - 1.0\text{A} < 0.1\text{A}$，强行设定为 `0.1A`，确保闭环控制的基本工作区间。
- **上限钳位防卫**：计算得到的目标值不得高于 `10.0A`。若 $I_1 - 1.0\text{A} > 10.0\text{A}$，强行设定为 `10.0A`，防止超出 DAC 的物理量程限制。

## 5. 安全动作联动与被重置后的行为控制

内阻计算任务不是完全独立的，业务代码必须支持并强制约束以下安全联动行为：

### 5.1 IOC 观测值与后续限流策略
- 当前实现中，`IOC` 是随 `[Calc]` 报告输出的**观测/占位值**：在 `STATE_LATCH_2A` 中暂以 3A 锁存点电流 `I1` 写入 `output->ioc`，用于让 GUI 与日志保留限流字段显示。
- 当前实现尚未根据 $R_{int}$ 动态计算最大安全控制限制电流，也不会在 `STATE_CALC_RESISTANCE` 后主动改写 DAC 限流目标。
- 计算完成后，状态机转移至 `STATE_MONITOR`，释放主动阶跃控制权，保证后续业务不会再次由内阻状态机主动改变 DAC 的硬件输出。
- 若未来实现基于内阻的动态 IOC 限流策略，必须先在本节补充公式、边界条件、限幅规则和对应回归测试，再修改 `calc_control.c`。

### 5.2 状态机紧急退回语义
- 在内阻状态机运转的任何阶段（无论是处于 3A 阶跃还是锁存阶段），如果高优先级保护任务发现物理量越限并向 `Calc_Control_Task` 下发重置请求：
  - 内阻状态机必须立刻终止当前的所有计时、采样和 DAC 控制行为。
  - 状态机状态必须强行退回到起点状态 `STATE_WAIT_SAFE`，并清空锁存值、3A 稳定计数和 2A 挂起标志。
  - 调用方将目标控制电流置为 `0.0A`；只有在保护状态机重新进入 `STATE_NORMAL` 后，才允许开启下一次单次触发测量。

### 5.3 上电冷启动状态联动 (Power-on Startup Coordination)
- **冷启动防冲击观察期**：系统上电后，保护状态机处于 `STATE_TRIPPED` 并向 `STATE_RECOVERY_WAIT` 转移。在 **2.0 秒安全观察期** 内，由于保护任务未进入 `STATE_NORMAL` 状态，`safe_allowed` 始终保持为 `false`。
- **DAC 零电流保护**：计算状态机在 2.0 秒观察期内被强制锁定在 `STATE_WAIT_SAFE`，DAC 目标控制电流输出维持为 `0.0A`，物理总闸（OF_EN）保持低电平。
- **自动使能物理输出**：2.0 秒防冲击观察期结束后，保护任务自动拉高 OF_EN（打通物理总闸）并切换至 `STATE_NORMAL`。
- **自动触发阶跃**：计算任务在下一个周期立即检测到 `safe_allowed == true`，状态机自主触发转移进入 `STATE_SET_3A`，开始执行 DAC 输出 3A 并进行动态稳定判定。
